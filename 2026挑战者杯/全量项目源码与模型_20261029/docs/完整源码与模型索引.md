# 完整源码与模型索引

本表以 `runtime/latest/openpi--main/` 为主项目根，供审阅者查找技术实现。文件是否参与当前采集入口、是否为历史扩展，需结合运行模式区分。

| 内容 | 主要路径 | 作用 |
|---|---|---|
| 启动与模式选择 | `run.ps1`、`start_shared_grasp.ps1` | 统一解释器、工作目录与各功能入口 |
| 共享采集主循环 | `openarm_cloth/run_human_task.py` | 连接人手观测、共享任务、执行与记录 |
| 人体/手部观测 | `openarm_cloth/live_bimanual_stream.py`、`human_teleop_core.py` | 摄像头、人手关键点、质量检查和身份关联 |
| 当前单臂位置控制 | `frontal_image_wrist.py`、`human_palm_depth.py`、`shared_human_control.py` | 图像平面、掌部前后信号、相对控制与连续性 |
| 意图与控制权 | `shared_grasp.py`、`shared_grasp_intent.py`、`shared_interaction_ui.py` | 捏合请求、阶段化控制、操作提示与异常恢复 |
| 机器人执行与视觉规划 | `shared_grasp_robot.py`、`human_task_robot.py`、`member_b_actuators.py`、`b_scene_fusion.py` | RGB-D、IK、路径约束、夹持与执行器 |
| 数据与回放 | `shared_dataset.py`、`replay_human_task.py`、`validate_human_task.py` | 图像索引、原始时序、动作重执行与结构校验 |
| 专用采集工具 | `runtime/dataset/scripts/`、`config/`、`tests/` | 多相机采样、分批、试次、审核、复核与数据契约 |
| 仿真桌面场景 | `openarm_cloth/simulation/` | 场景 XML、网格、工作空间配置 |
| 官方机器人模型 | `openarm_cloth/official_openarm_mujoco/` | v1/v2 机械臂、夹爪、网格与附属模型源码 |
| 机械设计资源 | `openarm_cloth/camera_cad/` 及根目录 STL | 机械臂与相机 CAD/STEP/STL |
| 相机与个人标定 | `openarm_cloth/calibration/`、`runtime/dataset/calibration/` | 相机几何、手眼与个人捏合配置 |
| Pose2Arm 技术库 | `pose2arm-main/*.py` | 人体与手部提取、坐标重定向、IK、夹爪映射、滤波、碰撞与规划 |
| Pose2Arm 与 B 接入 | `openarm_cloth/pose2arm_task_mapping.py`、`a_reference_adapter.py`、`run_a_reference_on_b.py` | A 参考与 B 机器人、回放的适配；按模式使用 |
| 原人体检测模型 | `pose2arm-main/models/` | MediaPipe Tasks 与本地已有的 RTMPose ONNX 等资产 |
| 原视频与参考数据 | `pose2arm-main/videos/`、`data/`、`out/` | 主项目中已经存在的参考视频、动作和分析输出 |
| 原强化学习/Isaac | `pose2arm-main/rl/`、`train_retarget.py`、`requirements-rl.txt` | 历史研究代码与 USD；保留源码，不作为本次训练成果 |
| 原 Gazebo | `pose2arm-main/gazebo_openarm/` | URDF/xacro 与对应网格；单独依赖其运行环境 |
| 辅助脚本与测试 | `pose2arm-main/scripts/`、`tests/`、`openarm_cloth/test_*.py` | 数据生成、重建、碰撞、几何、规划及控制验证工具 |

当前共享采集默认用单臂手腕相对映射，不代表所有 Pose2Arm 离线重定向、双臂和 RL 路径同时启用。完整收录用于交付技术链和源码，不把模式共存描述成已训练的统一策略。

环境方面，MuJoCo 采集主线按 `runtime/requirements_collection_verified.txt` 的本机版本验证。Isaac/Gazebo/RL 的第三方运行时并未打包进来，应按各自原说明准备；不需要这些额外运行时即可使用采集主线。
