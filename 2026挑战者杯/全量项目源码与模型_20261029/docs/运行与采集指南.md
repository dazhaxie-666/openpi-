# 运行与采集指南

## 1. 部署与环境

先执行包根目录的 `部署副本.ps1`，默认复制至 `D:\openpi\challengecup_runtime_20261029`。它拒绝覆盖已有目录。若选择其他位置，须纯英文路径。之后示例中的路径同步替换。

```powershell
$taskPython='D:\ProgramData\Anaconda3\envs\openpi\python.exe'
$taskDataset='D:\openpi\challengecup_runtime_20261029\dataset\dataset.ps1'
& $taskDataset -Mode Check -Python $taskPython
```

其他电脑建议使用本包实测 Python 版本，优先安装 `runtime/requirements_collection_verified.txt`（本次验证环境的直接采集依赖）。完整版本见 `evidence/environment_freeze.txt`，其中含其他研究工具，不要求全部安装。原 `latest/openpi--main/openarm_cloth/requirements_live.txt` 为历史版本约束，与本机实测版本有差异，原样保留但不作为本交付包首选。四个 MediaPipe `.task` 文件已附带，无需当场下载。

包内标定来自当前机器，换相机、操作者或机位应重新检查；不要把个人捏合标定当作所有人通用。GUI 操作需要 Windows 桌面和可用摄像头。

## 2. 优先采集 Hold 任务

```powershell
& $taskDataset -Mode Pilot -Task Hold -Pose center -Trials 2 -ResetSeconds 3 -Seconds 0 -Batch 1 -Operator operator01 -Python $taskPython
```

SPACE 开始，右手控制靠近，看到允许抓取提示后捏合。机器人辅助抓起并保持 3 秒，之后新的张手请求原位放下。Q 保存退出。当前阶段和提示以界面为准。此处先用两段试采确认最新版本与相机工作正常，不要求训练。

搬运任务使用 `-Task PickPlace`，抓起后手动移至绿色区再张手。两个任务保存到各自目录。

## 3. 查找与审核

新记录位于部署副本 `dataset/raw/<任务阶段名>/batch_001/<session>/`，不会写回原工程。

```powershell
$taskSession='D:\openpi\challengecup_runtime_20261029\dataset\raw\<任务阶段名>\batch_001\<session>'
& $taskDataset -Mode Audit -Session $taskSession -Python $taskPython
& $taskDataset -Mode Replay -Session $taskSession -Python $taskPython
& $taskDataset -Mode Summary -Task Hold -Python $taskPython
```

`Audit` 写独立审核报告；`Replay` 以执行器动作重执行，并在该副本样例目录新增 `raw_action_replay.json`，不改原始数组；如需观看可加 `-Visible`。执行前将占位路径替换为实际 session。

审核关注 recording_valid、结构错误、图像实际频率/缺口、trial 结果、需要人工查看的标记。不能用整个 session 有一次成功推断所有段都成功。视觉复核与训练批准是另一层工作，本次比赛可保留“试采数据”身份，不需要操作 Review 假造审批。

## 4. 自检与测试


Smoke 不需要真人，结果标 synthetic；不能混算真人成功率。测试会在部署副本产生 tmp、logs 和 reports，原工程保持不变。

## 6. 常见问题

- 中文路径被拒绝：先部署到英文目录，不能直接双击 runtime/run.ps1。
- 找不到解释器：显式传 `-Python`，本包不依赖原 `.runtime.local.json`。
- 已有部署目录：选择一个新英文目录；部署脚本不清理或覆盖旧记录。
- 相机被占用：退出其他摄像头程序；检查 Camera 参数。
- 未完成/取消：保存并检查原因，不修改成 completed。
- 文档中的旧训练计划：属于原始资料，本次验收不包含训练。
