# 项目方案：基于视觉遥操作与人机共享控制的仿真操作数据采集系统

## 1. 项目目标

利用已有普通 RGB 摄像头人手输入与 OpenArm/MuJoCo 环境，实现可实际操作的数据采集工具，交付结构化轨迹、机器人多视角 RGB-D、状态、动作、阶段与任务结果。比赛当前目标到“采集并检查数据”为止，不依赖策略训练效果。

建议作品名称：**基于视觉遥操作与人机共享控制的仿真操作数据采集系统**。

## 2. 技术路线

```text
现实单目 RGB 摄像头
→ 人体/手部关键点、相对腕位移与捏合意图
→ 人工靠近、机器人辅助抓取、人工搬运/定时保持、辅助释放
→ 唯一 B 执行器控制器与 MuJoCo 动力学
→ 三视角 RGB-D＋机器人状态＋动作目标＋时间＋阶段＋结果
→ session 保存、trial 分段、基础审核与回放
```

现实相机负责人的输入；胸部、左腕、右腕仿真相机负责机器人 RGB-D。输入端低门槛不等于单目恢复了精确米制深度。系统不重新训练手部模型。

## 3. 两种现有采集任务

| 任务 | 工作流程 | 当前用途 |
|---|---|---|
| Hold | 人工靠近→捏合请求→辅助抓取提起→稳定保持 3 秒→新的张手请求→原位支撑放下 | 优先交付，已有两段真人成功试采 |
| PickPlace | 人工靠近→辅助抓取→人手 XYZ 搬运→张手请求→辅助下降放置 | 现有扩展任务，独立记录，不混入 Hold 标签 |

主任务是已知红方块、单臂、桌面仿真。其余几何物体模块保留为基础代码，不据此宣称共享流程已经验证任意物体。

## 4. 人机分工与执行约束

人的输入表达位移与抓放意图；机器人完成局部视觉对准、夹持确认和支撑释放。自由靠近与搬运使用相对位置映射，自动阶段按状态机交接控制权，只有一套执行器目标生效。

使用现有工作空间、关节与速度限制、IK 和碰撞检查。无效观测、不可达放置和失败重试都有阶段与原因记录。持物时不因丢手直接松爪；目标先验与新观测分开标记，历史几何不能单独授权新抓取。上述为指定仿真范围内的保护，不是实体安全认证。

## 5. 数据产物

一次运行保存为 session；其中一次尝试按 trial 标记起止行，保留成功、失败、取消、中断。当前采集配置可能从捏合请求开始分段，是否含人工靠近必须读取实际 `includes_human_approach`、`segment_schema` 等字段，不预设全部片段同一范围。

| 文件/目录 | 内容 |
|---|---|
| episode.npz | 时序状态、动作、时间、阶段与输入质量 |
| shared_rgbd/ | 按相机保存 RGB 和米制深度 |
| shared_frames.jsonl | 图像、控制行与时间的对应关系 |
| shared_trials.json | 每次操作范围、终止原因、独立物理评价 |
| shared_phases.json | 控制阶段变化 |
| manifest.json / collection.json | 字段、坐标、采样配置、操作者、来源与版本 |
| quality_report.json / 独立 audit 报告 | 完整性、时序、任务条件与需复核项 |
| scene.mjb | 本次仿真模型快照，供重执行 |

动作目标与实际状态不同；关节角用弧度，手指位置用米，深度用米。完整 qpos 包含仿真环境信息，不能整体当作机器人观测。即使当前不训练，也保留这些语义边界。

## 6. 已实现与验证范围

- 采集、异步图像保存、分段、失败保留、批次管理、基础审核与回放工具已经实现。
- 包内真人试采为两个 Hold 成功段，非合成输入，结构有效；历史相机为胸部和右腕约 10 Hz。原报告仍保留需人工复核、未正式批准状态。
- 最新三相机代码的软件自检三路各 151 帧，动作重执行通过。它验证软件链路，不替代新版本真人操控验收。
- 本次复制后的环境检查、采集相关测试和样例重执行结果写入 evidence/；以实际报告为准。

## 7. 设计贡献与使用价值

1. 普通视觉输入和阶段化共享辅助结合，减少操作者精确对准负担。
2. 图像、实际状态、动作与控制权信息一起记录，使轨迹可解释、可复核。
3. 原始记录与试次标签、审核结果分离，失败不覆盖、试采不改名冒充正式数据。

以上是工程设计贡献，不把 MediaPipe、OpenArm、MuJoCo 或共享控制概念宣称为原创。当前面向教学、实验室方法验证和操作示范采集。

## 8. 本次交付验收

能从独立副本启动；真人完成至少一次目标操作；多视角图像与状态动作实际落盘；操作段有起止和结果；审核报告可读；样例能回放。最新三相机真人试采仍需现场进行，不能由自动检查代替。

无需为了本次要求增加模型训练、公开数据集、大规模采集或学习效果对照。正式采集数量按老师要求确定，不沿用旧训练计划中的 30/100/300 条作为比赛硬性指标。
