目标仓库：<https://github.com/dazhaxie-666/openpi->。
当前交互版本为 6，发布基于远端 main 新增提交，不改写历史。

## 本次运行方式

Windows 在仓库目录运行，指定已经配置好的 B 环境 Python：

```powershell
& .\start_shared_grasp.ps1 -Python 'D:\path\to\openpi\python.exe'
```

也可以设置 `OPENPI_PYTHON`，随后运行 `start_shared_grasp.ps1`。
现有用户可继续使用本机外层的 `D:\openpi\启动共享抓取.ps1`；该本机快捷脚本不要求出现在新电脑的相同路径。

新环境依赖见 `openarm_cloth/requirements_live.txt`；检测器权重通过 `openarm_cloth/setup_models.py` 下载。
`check_runtime.py --check-models` 可检查依赖、模型和场景。把仓库放在纯英文路径，避免 Windows MuJoCo 的资源路径问题。
个人夹爪标定保留在各自机器上，仓库不附带本机个人试次或标定文件。

## 当前行为

- 自然张手靠近，进入抓取范围直接新捏合，无需范围内再次张手准备或按键切换。
- 新捏合由二维、三维指尖距离共同确认；重复帧和范围外旧闭合不直接触发抓取。
- 目标被遮挡时，上抬幅度跟随人手，取消固定高度自动上升。
- 自动精确抓取与提起后交回人工搬运；张手请求支撑放下，不要求再次捏合。
- 放置不可达时保持夹持并恢复搬运，支持有界腕姿解；松爪后的遮挡退出与提示已接入。
- 完整试次分段、异步机器人 RGB-D、质量检查与实际动作回放继续保留。

这是已知红方块的共享遥操仿真，不包含任意物体识别或已经训练完成的自主策略。
