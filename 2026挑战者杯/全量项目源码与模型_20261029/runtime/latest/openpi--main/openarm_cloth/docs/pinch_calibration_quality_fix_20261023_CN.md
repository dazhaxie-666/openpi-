# 个人捏合标定：区分保持噪声、开度差异与标签不一致

真人重复标定仍显示 NOT READY。核对两轮各 10/10 的采样，并将后一轮采样对应到原始录像后，确认存在两个独立原因。

1. 旧质量判据以不同试次的中位值标准差估计噪声，再要求端点间距大于其六倍。张开幅度在各次有所变化，即使每次保持稳定、两类样本分得开，也可能被拒绝。
2. 后一轮有一次标为 open 的采样，录像对应画面仍在捏合，测量值也落在 closed 范围。这种标签不一致必须处理，不能降低门槛强行拟合。

## 修复与保持的条件

`PinchCalibration.fit()` 改用每次保持期间的样本标准差，取各类别的试次中位数后再取两类的较大值，估计保持噪声。仍要求保守端点（closed 的95分位、open 的5分位）间距超过 `max(0.05, 6 * noise)`。不同次开度的差异仍体现在这些端点分位数里，不再当作同一姿势下的跟踪噪声重复处罚。

仍要求每类至少10个有效试次；单次采样数量、单次稳定性、标签反向、两类重叠与二维/三维一致性检查均保留。没有自动删除异常试次，没有自动交换 G/O 标签，也没有降低人体/手指识别置信度。

真正端点重叠仍报告 `OPEN_CLOSED_DISTRIBUTIONS_OVERLAP`。端点未重叠但间距不足以超过噪声门槛时，改报 `OPEN_CLOSED_MARGIN_TOO_SMALL`，不再混称重叠。
