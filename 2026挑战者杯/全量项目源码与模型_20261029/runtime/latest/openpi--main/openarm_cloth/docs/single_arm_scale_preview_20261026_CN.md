# 50 秒现场记录复核：短时掌部尺度补偿与显示负载调整

## 本次现场证据

记录 `outputs/human_task/20261026_131335_075558` 正常完成约 50.05 秒引导，
录像有效、后台写入无掉帧、无程序错误。738 个活动控制行对应 682 个新来源观测。
原始前后有效 594/682（87.1%）；52 个新来源因重投影不确定保持，14 个丢手，
16 个掌形不确定，另有初始标定和跳变确认。

737 次 IK 中，735 次通过现有几何门限（99.7%），2 次因初始腕姿超过 20 度保持。
映射目标、限速后关节目标对应的 TCP 与实际 TCP 总体相随，实际前后跨度约 114.4 mm。
因此这次的主要停顿出现在感知层，不能笼统说整条 IK/执行链路没有前后响应。

原画面约第 28.5–31 秒手明显靠近镜头，前后输入却在约 -4.4 mm 保持；
模型投影误差约 13–19 px。用完全相同的保存掌点、身体观测和来源时间戳重放原算法，
与录制输入最大差异为零，确认精确复现了这个停顿。

静止提示段导出波动约 7.2 mm 与 32.9 mm，但原视频末尾仍有抬手、放下动作，
初始段也含摆位过程；这些是**提示段内的观测变化**，不能冒充纯传感器静止噪声。
同样，near/far 提示标签不能替代原画面中的动作真值。

## 新增的有限补偿

保留原三维投影与所有质量门限。仅当三维重投影误差过大、完整五个掌点仍被接受时，
允许以下独立二维观测补偿：

- 与最近可靠投影时的二维掌形做相似匹配，去除横向平移和平面内旋转。
- 要求均匀尺度拟合的归一化残差不超过 6%，尺度比在 0.6–1.7，参考掌形不能近似共线。
- 可靠三维投影参考最多保留 0.75 秒；补偿观测不能续期，须由新的可靠三维投影更新参考。
- 从观测到的尺度比计算相对距离比例，沿用同一相对增益、滤波和大跳变两来源确认。
  不预测丢手期间的位移，不对严重形变/裁切/微小手掌或已要求重定中心的输入启用补偿。
- 画面和日志明确标记 `DEPTH_SCALE_TRACKING`；名义 Z 仍不是经标定的真实距离。

肩宽只作为诊断字段，不负责手部前后控制。B 的模型、PD、力矩、工作区、碰撞检查、
20 度腕姿限额及关节速度限制均保持原行为。
