# 前后移动被夹爪条件和重归零截断：现场复现与修复

## 证据

用户反馈“依旧无法识别前后移动”后，复核了本机真人记录
`outputs/human_task/20261025_232741_221304`。活动段 210 行中，前后输入仅
47 行有效，100 行被 `DEPTH_GRASP_SETTLING` 暂停。手部伸出、收回同时造成
开度估计变化，上一版错误地把这种变化作为整条前后通道的暂停条件。
这是实现问题，不能归因于用户拍摄角度。

用保存的同一组掌部二维/三维观测、身体观测和来源时间戳重跑旧算法，
输出与原记录最大差异为零，确认复现了实际输入冻结。另一个问题是短暂
投影失败、身体闪断和手部重捕获会重新归零，吞掉已经发生的回收位移。

## 当前修复

- 夹爪开度不再决定掌部前后输入是否有效；独立可见的掌部平移与捏合可以同时进行。
- 可见掌部的几何拟合暂时失败时保持输出，保留原相对参考；稳定新掌形适配保持
  既有模板尺度，避免模型掌尺寸变化被当成真实距离。
- 连续可信的肩腕身份可以跨越最多 0.8 秒的短暂丢手，身体闪断最多保留参考
  0.35 秒。期间无有效观测仍保持输出，不预测移动。身份不连续、长时间丢失、
  暂停或来源时间断层仍重新对齐后恢复。
- 默认相对灵敏度由 0.35 改为 0.15，避免一次正常伸缩迅速耗尽约 22 cm 的
  B 工作区。输出 `-0.15 * log(z/z_reference)` 是控制位移，不是真实测距。
- SPACE 首次开始及 C 定中心重新采集五个新掌部观测，避免 READY 长时间等待
  期间的旧参考污染实际操作。既有捏合个人标定无需重做。
