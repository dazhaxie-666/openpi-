# 真人运动、夹爪和运行耗时的引导式诊断录制

本地命令：

```powershell
Set-Location -LiteralPath 'D:\openpi\latest\openpi--main'
& .\run.ps1 -Mode human-task -ScriptArgs '--mapping','wrist','--gripper-mode','continuous','--diagnostic-recording'
```

此模式明确授权保存本地原始人体视频，并关闭逐帧机器人相机 PNG 写盘；机器人自身用于观测/碰撞的视觉链路仍保留。它不改变映射增益、工作区、控制增益、限速、物理步长或碰撞检查。仅支持实时直接手腕模式；显式软件夹具检查只验证流程，不生成或伪装真人视频。

## 操作流程

点击 START 或按空格；手腕有效后进入 DIRECT，从此开始计算 65 秒活动时间。还未 START 时会录下等待过程，但不启动动作计时。暂停时活动计时停止，Q 可提前保存。需要更长末尾观察时可以加 `--diagnostic-seconds 90`，前面的动作提示时段不变。

| 开始后的活动时间 | 屏幕提示 | 操作 |
|---|---|---|
| 0–5 秒 | REST | 手腕放在舒适中心静止 |
| 5–15 秒 | LEFT_RIGHT | 缓慢左右往返，尽量保持高度和前后位置 |
| 15–25 秒 | UP_DOWN | 缓慢上下往返，尽量保持其他轴 |
| 25–35 秒 | FORWARD_BACK | 伸手、缩手，肩膀尽量不跟着前后晃 |
| 35–45 秒 | PALM_PINCH | 手掌朝摄像头，拇指和食指缓慢捏合、张开，重复约三次 |
| 45–55 秒 | BACK_PINCH | 手背朝摄像头，重复相同的捏合、张开 |
| 55–65 秒 | REST_END | 保持静止，等待自动保存或 Q 提前保存 |

始终保持完整肩肘腕和手指入镜。按屏幕提示做即可，不需要另外按数字标记。阶段标签来自时间提示，不是算法判定你实际完成了该动作，分析时会核对录像。G/O 仍可采集个人标定，但本次诊断建议保留原来的标定配置，避免边录边更改端点。C 重定中心、R 暂停重识别仍可用，数据中保留锚点和视觉代次，以便识别这些变化。

## 保存内容与时间对齐

输出：`openarm_cloth/outputs/human_task/<时间戳>/`。

- `human_diagnostic/human_camera_*.mp4`：后台分块编码的原始人体录像，不镜像。20 FPS 仅表示播放器速度，不能据此计算动作时长。
- `human_diagnostic/video_timestamps.csv`：每个视频帧对应源序号、相机返回时钟、控制行号和分块帧号。用它与 `episode.npz` 对齐，不能按视频帧号直接等同控制行号。
- `episode.npz`：人体原始/二维关键点、捏合特征与接受状态，阶段提示，人体与机器人锚点，未经裁剪目标、工作区裁剪目标、领先限幅目标、最终 Cartesian 指令、实际 TCP、关节目标与状态、保持/IK/碰撞原因。
- `diagnostic_summary.json`：按提示阶段统计手腕/手指通过率、各轴被工作区裁剪的控制行数，以及机器人视觉观测、输入/映射、IK/碰撞执行、前台图像记录、物理推进、界面、整循环耗时的中位数和95分位。阶段通过率不是手掌/手背识别准确率。
- 保存相机返回、推理完成、执行提交、物理推进起止的主机时钟。它们不包含相机曝光、USB缓冲前的延迟或执行器稳定时间。`pose_inference_ms` / `hand_inference_ms` 是后台各流水线到达完成点的时间，后者包含等待，不可简单相加作为模型总计算时间。

录像后台队列最多8帧，满时记录丢帧并返回，不在控制线程等待编码完成。其内存随排队帧数有界；编码仍占用CPU，所以不承诺对运行速度完全没有影响。`image_record_ms` 只统计前台复制/提交等工作，不包含后台编码耗时。`diagnostic_video.valid`/`diagnostic_video_valid` 会在丢帧、写入错误或未完成时为false，不能把不完整视频当完整证据。正常 `episode.npz` 的结构完整性单独检查。

主结果 `INCOMPLETE` 可表示本次没有完成抓放任务，不等于录制失败。检查 `recording_valid`、`diagnostic_video_valid` 和 `diagnostic_summary.json` 的 video 状态。软件夹具没有人体视频，因此其 `diagnostic_video_valid=false` 是预期，不能标为真人录制成功。

## 验证边界

软件回归验证了提示分段、工作区裁剪与实际限速目标分离、录像源序号/控制行/帧索引对齐、慢编码器下提交不阻塞且丢帧可见。显式软件集成验证了自动到时保存、诊断字段与结果结构。深色提示界面已生成本地预览并检查。尚未启动摄像头或完成本功能的新真人录制，录完后需要读取本地结果分析前后轴响应和手背识别。

原始录像、关键点、个人标定和本地测试输出保持本地，不随代码提交 GitHub；这些诊断样本不是已经筛选成功的训练示范。
