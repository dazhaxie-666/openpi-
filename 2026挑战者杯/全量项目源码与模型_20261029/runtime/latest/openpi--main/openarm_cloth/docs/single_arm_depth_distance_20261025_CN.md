## 本次实现

- `single-arm` 使用 `--position-frame upper-body`：肩线确定左右，
  相机竖直方向在肩线的正交平面内确定上下，二者叉乘确定前后；
  保留 Pose 模型的肩—腕三维向量，不从手掌大小推算绝对深度。
  该假设适用于相机竖直摆放、人体大致正对镜头的目前操作方式；
  相机明显侧放、倾斜或人体大幅侧转时不保证坐标方向准确。
  C 仍用于手与机械臂的相对位置重置，不是摄像头外参标定。
- 原 `human_wrist`、双臂/完整构型映射和辅助抓取的参考系保持原入口；
  `--position-frame original` 可显式对照原单臂坐标系。
- 手部长期丢失后，继续在可信身体手腕附近做局部裁剪搜索，
  与全图搜索并行。以前没有近期手部轨迹就跳过局部模型，
  全图难以识别的小手因此难以恢复。两帧确认、身份关联和质量检查继续生效。
- 预览增加 `WORKSPACE LIMIT: X depth / Y lateral / Z height`，
  以及 `ARM LIMITED - WORKSPACE BOUNDARY`，区别边界限制和观测丢失。
  周期记录新增 `position_workspace_clipped`；没有放宽工作区、碰撞阈值或执行器参数。

## 运行

```powershell
cd D:\openpi\latest\openpi--main
.\run.ps1 -Mode single-arm
```

相机竖直摆放并大致正对身体，在舒适中位按空格开始；工作区已到边界时
先返向，或将手放到新的舒适中位后按 C 重新对齐。
无需重做个人捏合标定。若要记录真实近远变化与前后响应，使用现有本地诊断：

```powershell
.\run.ps1 -Mode single-arm -ScriptArgs '--diagnostic-recording','--diagnostic-protocol','response'
```

原参考系对照：

```powershell
.\run.ps1 -Mode single-arm -ScriptArgs '--position-frame','original'
```
