## 新电脑运行

从仓库安装依赖并用 `setup_models.py` 获取检测器模型，按 `RUNNING.md` 配置 B Python。
`tabletop` 可从仿真场景直接启动，无需私人示范视频。

不能因为代码上传就认为本机 `outputs` 或默认回放随仓库存在。
部分轨迹/人体检测测试依赖本地私有样例，源码发布不承诺新机器无需素材即可重现所有测试。
