# 抓取范围提示与抓起后无法张手放下的修复

后续第二轮“张手已识别但下降失败”的修复与论文采用范围，见[放置优化](placement_release_research_20261027_CN.md)。

现场记录：`outputs/shared_grasp/20261027_184157_677403/`。

## 当前操作

1. 张手入镜，SPACE 或点击 START 开始。
2. 移动右手靠近。底部出现绿色大字 **“可以抓取：现在捏合拇指和食指”** 时，捏合请求辅助抓取。
3. 等待自动对准、闭合、确认和抬起，再用手腕搬运。
4. 抓牢后 **直接张手并稍作保持** 即可请求放下，不再要求抓起后额外捏合。
   底部显示 **“正在确认张手，请稍作保持”** 和进度；连续新鲜张手约 0.35 秒后，先下降到支撑面，再松爪、退出。

自动抓取完成前，持续张手约 0.7 秒仍表示取消；手部识别缺失或重复旧帧不会松爪。

## 提示含义

- 绿色“可以抓取”：同一状态机确认已开始控制、目标完整可见、参考点距方块表面不超过 75 mm、
  已完成张手准备、当前右手输入有效。它表示可以请求辅助规划，不保证每条候选路径都可行。
- 黄色：继续靠近、先张手准备、让拇指和食指入镜，或目标遮挡需向上退开。
- 蓝色：自动抓取、张手确认进度或正在放下。
- 持物缺手时提示保持夹持；不会把缺手当成放下意图。

提示位于摄像头图像下方，不遮挡手部骨架，使用本机字体显示中文。提示图块及字体缓存，
图像预览继续在已有异步显示线程运行；未增加识别模型。

## 这次放不下的原因

38.780 秒进入搬运。搬运期间没有再次被确认的闭合，但识别到 39 个有效张手控制帧；
其中有连续约 0.78 秒、0.72 秒的有效张手。
旧逻辑要求“搬运开始后再识别一次闭合”才能准备放下，因此一直保持夹持。

新的闭合基准来自本次已接受的捏合抓取及机器人夹持确认。交接时清空张手确认计时，
只接收交接之后的新序号、新时间戳张手观测；不再增加重复捏合这个门槛。
保持原有下降、碰撞检查、支撑高度修正、松爪和退出流程。
