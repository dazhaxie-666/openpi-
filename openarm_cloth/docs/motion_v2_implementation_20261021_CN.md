# 双臂动作跟随 v2：实现、验证与操作

2026-10-21。依据用户提供的《动作映射改进方案》第二版实施。该方案的“≥99%”是独立验收目标，当前没有达到该结论所需的独立测量和新真人试验。本次上传的是开发版本。

## 改了什么

| 方案项 | 本次实现 | 当前边界 |
| --- | --- | --- |
| P0 分层定位 | 保存原始姿态、接收姿态、A 名义 IK、完整腕部目标、执行端目标、实际关节；来源序号、时间与模块原因独立记录 | 普通摄像头没有曝光时间；宿主机时间不等于曝光到动作总延迟 |
| P1 躯干与身份 | 来源序号/时间先于滤波检查；可靠髋部或已标定上身参考；尺度、骨长、姿态创新检查；手腕像素关联、有限时间身份预测、交叉歧义拒绝、连续新帧恢复 | 上身模式假设相机竖直、基本正对；大角度转身需重新标定。预测只辅助关联，不生成虚拟手关键点 |
| P2 抓取 | 双手分别记录闭合/张开试次；掌尺度归一化 3D 与可观测 2D 比值；分位数/可分性检查、时间确认、连续开度；可选二值迟滞 | 每侧至少 10 次闭合、10 次张开且分布可分才算个人标定完成；未标定使用明确标记的通用端点 |
| P3 手腕 | 掌面相对前臂的 SO(3) 旋转；B 三个腕关节定向求解；保留 A 肩肘四关节；相对姿态保持、旋转创新拒绝和来源时间滤波 | 单目真翻转无法靠四元数改符号修复；不可达目标输出残差，不能宣称已经跟到 |
| P4 执行 | 最新观测槽、独立物理线程与显示数据；按实际墙钟间隔推进；报告超时和未推进时间；responsive 去掉重复关节低通，保留速度/加速度边界与 B 原执行器 | 40 Hz 是调度目标，负载下允许超时并如实记录；不是硬实时控制器 |
| P5 回归 | 来源重复、遮挡保持、重新捕获、端点重叠、真假 180°、三轴手腕、慢界面等回归；已有失败录像作开发输入 | 历史录像与重复播放全部属于开发集，不计独立成功率 |
| P6 验收 | 15 秒开发片段标记、独立参考模板、实际物理轨迹比较、时间加权可用率与精确单侧成功率下界工具 | 未采集 400 个独立试次；未完成独立输入资格、接触/身份、跟随延迟审查，发布评价为 NOT_EVALUABLE |

原始 `pose2arm-main` 映射源文件没有因本轮修改而重写。A 接收的是明确记录的躯干参考与原始肩肘腕；`a_nominal_joints` 保存 A 输出，最终腕部目标可以与其不同。默认映射不再声称“最终七关节与原 A 完全相等”。

`live` 使用 B 无桌面、无物体的动作场景，不自动规划抓取、避障或接管动作。`human-task` 接入同一人体映射/个人夹爪配置，但继续保留 B 桌面碰撞检查和右臂任务评分，其执行循环没有本轮自由跟随线程的性能保证。

## 操作

```powershell
Set-Location -LiteralPath 'D:\openpi\latest\openpi--main'
& .\run.ps1 -Mode live
```

1. 相机正立、照明充足，头、双肩、双肘、双腕及手指保持在画面内。左手控制机器人左臂，右手控制右臂；预览默认镜像，M 切换镜像不改变识别输入和左右身份。
2. 正对相机，双臂稍离开身体、肘部自然弯曲，双掌朝相机，保持约 1–2 秒。先标定躯干，再由 A 分侧收集 10 个有效帧标定臂长。髋部不可靠时 auto 使用明确标记的上身参考；虚拟髋点只是坐标构造，原始检测值另存。
3. 做个人捏合标定：双手拇指与食指合拢，按 G，维持至少 1.2 秒；松开，按 O，维持至少 1.2 秒。交替重复至少 10 轮，直到左右 `closed/open` 计数都至少 `10/10`，且标定通过。一次长按或一段长视频不等于十次试次。左右手可以同时采样，某侧不可见时该侧试次会拒绝。
4. 然后缓慢摆臂、屈肘、翻掌、捏合。默认夹爪连续开度。按 T 标记一个 15 秒开发片段；它只标记时间，不产生动作真值或自动成功判定。空格暂停，C 重标定身体/腕部，Q 保存退出。C 保持夹爪现有开度及个人端点配置。

个人标定随正常退出保存到忽略提交的 `openarm_cloth/calibration/personal_motion/pinch.json`，每次录制另存副本。使用不同相机、人员或明显不同姿态时，应使用独立配置重新采集，避免把不同条件的样本混到同一标定中：

```powershell
& .\run.ps1 -Mode live -ScriptArgs '--calibration','calibration/personal_motion/new_session.json'
# 只对比经过个人标定的二值夹爪
& .\run.ps1 -Mode live -ScriptArgs '--gripper-mode','binary'
# 明确坐姿上身参考；仍需基本正对相机
& .\run.ps1 -Mode live -ScriptArgs '--torso-mode','upper_body'
# 髋部始终可靠可见时，强制完整躯干参考
& .\run.ps1 -Mode live -ScriptArgs '--torso-mode','full_body'
# 保留 A 原腕部目标作对照
& .\run.ps1 -Mode live -ScriptArgs '--wrist-mode','off'
# 任务模式复用同一默认个人配置，桌面碰撞约束仍可能保持某侧
& .\run.ps1 -Mode human-task
```

`--torso-mode original` 只用于旧实现对比，缺失髋部时不具备新参考的保证。`--execution-profile smooth` 用于旧关节滤波对照，默认 responsive。`twist` 保留旧 A 腕部行为供比较，只有 `full` 接入完整掌面旋转。`--mapping b-legacy` 是旧 B 路径，不包含本轮全部功能。

## 卡住时怎样定位

- `TORSO_CALIBRATING`：躯干还没有稳定标定；`UPPER_BODY_TURN_RECALIBRATE`：转身超过可观察工作范围，正对后 C 重标定。
- `ARM_BONE_LENGTH_*`：当前骨段不合理或与本人标定差别过大；检查遮挡、距离变化、是否识别到了其他人。
- `association LOST`：手没有可靠对应到人体手腕；不要靠近身体遮住手腕或让两手交叉重叠。
- `PALM_*OUTLIER`：掌面朝向发生无法解释的突变；先恢复清晰正面。持续真正的大角度错误不会因重复同一结果自动当作可靠，需要重新标定腕部。
- `PINCH_CONFIRMING`：正在等待不同来源帧的时间证据；`UNCALIBRATED_ENDPOINTS` 表示仍在使用通用端点；`PINCH_2D_3D_CONFLICT` 表示两类观测不一致，保持现有开度。
- 模块 `HOLD/LOST` 只停止对应更新。短时丢掌保持相对前臂腕姿态，丢手保持夹爪，重新捕获需新帧证据，不自动松爪，也不把抓空强制判为失败。

这些规则能拒绝一部分错误，无法证明每个通过门控的单目检测都正确。新的录像仍需逐帧独立检查，不能把更高跟踪覆盖率解释成更高精度。

## 数据与复核

新录制保存在 `openarm_cloth/outputs/a_live/<时间>/`：

- `dataset/`：带来源时间的分层字段、模块状态/原因、个人标定 ID、相机关键点与可选原视频。
- `physics_trace.npz`：实时模式每个物理控制周期的实际关节、动作、模块状态及其参考来源；不依赖界面保存频率。
- `personal_calibration.json`、`motion_diagnostics.json`、`independent_reference_template.json`：个人配置、全时间分母诊断、待独立填写的参考模板。
- `scene.mjb`、源哈希、`quality_report.json` 和 `summary.json`：重现与数据完整性证据。软件合成检查明确标记 synthetic，不写入正常个人配置。

```powershell
& .\run.ps1 -Mode python -ScriptArgs 'evaluate_motion_v2.py','outputs/a_live/<时间>','--output','outputs/a_live/diagnostics.json'
& .\run.ps1 -Mode python -ScriptArgs 'evaluate_motion_v2.py','outputs/a_live/<时间>','--reference','outputs/a_live/independent_reference.json'
```

独立参考要求 B 模型世界坐标、宿主机单调时钟、两名审核者、测量不确定度及实际姿态/事件/静止段。不能复制本检测器输出冒充真值。缺少参考、独立资格或接触/身份/延迟审核时是 `NOT_EVALUABLE`。本工具提供开发诊断和单段比较，不构成已完成的正式 400 段验收管理系统。

单侧 95% 精确下界需达到 99% 才可作该范围声明；400/400 的下界约 99.254%，399/400 与 990/1000 均不足。新的独立数据必须在调参后留出，不能反复重放开发录像充数。

## 依据

MediaPipe 的 pose 与 hand world landmarks 使用不同的原点；本实现只旋转手部向量，不拼接世界位置：[Pose Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/python)、[Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python)。四元数 q/-q 等价，并不能纠正真正错误的掌面旋转：[SciPy Rotation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.transform.Rotation.as_quat.html)。

下一步需要新摄像头试验：固定取景和个人标定后，分别测静止、慢动作、快动作、侧掌、短遮挡和两手交叉，先确认失效来源，再决定是否增加双相机/深度或更换关键点模型。当前没有训练新识别模型或添加实体机械臂驱动。
