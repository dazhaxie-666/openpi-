## 日常操作

```powershell
Set-Location -LiteralPath 'D:\openpi\latest\openpi--main'
& .\run.ps1 -Mode single-arm
```

这就是正常入口，不需要每次运行检测脚本、50 秒分轴测试或诊断录制。
SPACE 开始/暂停，C 定中心，Q 保存退出。开始时的掌形参考在后台自动采集，
不要求重做已有 G/O 个人捏合标定。换镜头、操作位置或中立姿势后按 C 重新定中心。
日常运行仍保存基础数值日志，默认不保存人体视频，也不运行定时动作提示。

模型首次准备一次即可，本机已经安装，不需要重复执行：

```powershell
& .\run.ps1 -Mode python -ScriptArgs 'setup_models.py','--rtmpose'
```

## 已确认的错误

真人记录 `outputs/human_task/20261026_133117_271795` 约第 17–21 秒，操作者拉远，
真实右肘仍在画面内，MediaPipe 却把肘点估到画面下方。例如原第 19 秒，
右肘归一化纵坐标约 1.17、置信度约 0.92。
对同一原帧重新用 IMAGE 检测、heavy 模型以及局部裁切作了对照，
仍有明显误差，不能将简单重启作为根本修复。

另有两个实现缺口：完整手臂质量检查未拒绝越界肘点；预览按手腕有效性
把整条手臂涂绿，导致高置信错误肘点看上去仍可信。这两处都已修正。

## 正常流程的修改

单臂采用 RTMPose-S 当前图像的二维肩、肘、腕观测，并保留 MediaPipe 手部识别：

1. 二维身体模型逐帧运行，无 VIDEO 历史骨架锁定状态；与原身体和手部识别并行。
   自动使用当前操作者附近的宽裁切，缺少可信上下文时恢复全图，不要求用户反复按 R。
2. 当前帧两个模型的人脸位置须一致，肩腕须达到对应模型的质量门限并位于画内。
   缺失或不同人的估计不能凭旧观测直接授权手臂移动。
3. 左右/上下使用肩腕二维相对位置，并以当前肩宽归一化；控制尺度为名义 0.4 肩宽单位，
   不声称是真实人体米制坐标。现有来源时钟滤波保持运动连续。
4. 前后仍由独立掌部投影与已有有限二维尺度补偿提供；不从肘部或新二维模型伪造深度。
5. 预览单独检查整臂质量。越界/不可信肘段不会因手腕有效而显示为可信绿色。
   肘不可靠时，独立可见的肩腕位置与手指通道仍按各自质量处理。
6. 单手局部搜索不再从低置信或越界的肘点朝错误方向外推裁切；双手历史裁切规则保留。

RTMPose 的原生峰值分数采用 0.45 门限，不能把它当作 MediaPipe 可见度概率；
MediaPipe 的身体门限仍为 0.6。原始 RTMPose 17 点分数保留在日志中。
额外保留 MediaPipe 当前帧人脸的一致性检查。没有通过更改原 MediaPipe 门限来掩盖错误。

`human_pose_norm`、`human_pose` 继续保留原身体模型输出用于对照；
`human_position_pose_norm` 才是当前单臂实际使用的二维身体点，Z 明确为 NaN。
这些二维点不作为人体三维骨架，也不直接赋给机械臂关节。
B 的 IK、动力学、工作区、PD/力矩、碰撞检查和腕姿限额沿用原实现。

## 验证结果和限制

将原录像中约第 15–30 秒片段送入生产识别流，真正打开摄像头预览和 MuJoCo 窗口，
运行当前输入映射、原 B 动力学：

- 274 个活动采样中，肩腕位置有效 274 行，掌部前后有效 261 行。
- 同一批新识别帧中，原 MediaPipe 肘点越界 108 行，新实际二维肘点越界 0 行。
  已按真实原视频帧 ID 逐帧抽查第 17、19、21、23、25、27 秒；新肘点更接近实际弯折。
  越界数只是可观测性指标，不是“肘部准确率 100%”。没有独立三维肘部真值。
- 控制约 18.74 Hz；二维身体推理中位数约 22.9 ms，p95 约 26.8 ms。
- 281 帧 B 动作重执行通过，qpos/qvel 最大差异均为零，证明本机同模型动作重放一致。
- 部分目标仍触及初始腕姿 20 度约束并保持，该限制没有取消。

证据保存在本机 `outputs/depth_diagnostics/gui_133117_rtmpose_native/`，包含
`active_elbow_contact.jpg`、`elbow_review.json`、`episode.npz`、`action_replay.json`。
此前 full、heavy、不同裁切与模型对照保存在 `20261026_live_133117/`；失败实验保留。
上述都是保存录像回放，不冒充新真人验收。正常使用时仍可能受遮挡、极端转身和距离限制。

新增回归覆盖越界肘点、低置信肘部的单手恢复裁切、显示质量与手腕质量分离、
二维源不提供伪三维、坐标轴/尺度、不同模型分数语义、当前帧双模型身份一致性，
以及真实流编排中保留原始错误点而实际采用新二维输入。

## 论文和代码采用

本轮新增使用 [RTMPose，2023](https://arxiv.org/abs/2303.07399) 的官方 RTMPose-S 预训练二维模型，
模型与预处理规范来自 [OpenMMLab RTMPose](https://github.com/open-mmlab/mmpose/tree/main/projects/rtmpose)
及 [rtmlib](https://github.com/Tau-J/rtmlib)。使用现有 OpenCV DNN 推理，没有新增 Python 环境依赖，
没有重新训练，也未采用论文性能数字作为本机结果。只安装模型资产一次。
此前 OAT 掌部投影采用范围不变，没有接入 ESFP 的 ROMP/HPSTM。

仅主 `single-arm` 默认启用此输入；旧模型对照可显式使用
`-ScriptArgs '--body-position-source','mediapipe'`。双臂、纯动作回放和自主抓取模式不切换身体模型。
