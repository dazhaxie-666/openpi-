# 自动精细遥操与稳定夹持

现场追加版本已接入手掌平面转动、有界视觉居中及近物连续轨迹修复。
当前操作、作用范围和验证见[手腕与贴边抓取修复](wrist_edge_grasp_fix_20261026_CN.md)。
下文保留本轮追加之前的前三阶段实现与证据，自动视觉微调的状态以新说明为准。

当前默认入口已启用前三阶段：自动精细调节、受控接触、夹持确认与释放。
人手识别、掌部前后求解、固定图像左右/上下输入保持原版本，源文件 SHA256 与修改前一致。
没有加载新的三维神经网络，没有自动对准、自动抬臂或自动决定抓放时机。

新增辅助只改变 B 端的人机参考与执行策略；原 MediaPipe 手部、身体模型和输入映射可独立回退。

## 使用

```powershell
& 'D:\openpi\启动修复版遥操.ps1'
```

SPACE 开始/暂停，C 定中心，Q 保存退出。
靠近方块时自动逐渐降低灵敏度和速度；夹稳后恢复搬运灵敏度，撤离目标平滑恢复。
捏合闭合；确认夹持后自动保持目标开度，持续明确张手才释放。
短暂缺手不会自动松开，不要求按键切换精细模式或锁定开度。
V 仅作可选的自由/俯视/侧视视角切换；原 L/H 人工覆盖仍可选用。

要关闭本轮辅助、保留已经改善的人手输入与前后/左右映射：

```powershell
& 'D:\openpi\启动修复版遥操.ps1' -NoGraspAssist
```

## 控制与接触

- 自动精细程度依据已有机器人相机估计、夹爪位置及接近意图，带稳定确认、迟滞和渐变。
  最细时增益为普通模式的 25%，目标速度约 0.02 m/s，领先距离 8 mm。
  死区随同增益缩放，保留相同的人手输入噪声容限；没有增加图像时间滤波。
- 增益改变时连续衔接参考，收缩领先距离不能把目标反向拉回。
  精细区另外约束机器人端关节目标产生的 TCP 位移，避免已有目标积压绕过降速。
- 只允许目标方块与指垫内侧、方向合理的有界预期接触；指背、指尖边缘、手掌、连杆与桌面保护保留。
  原记录中检查到的背面/边缘碰触继续拒绝。
- B 指垫物理内表面与 TCP 代理点约有 7.2 mm 偏置。判定使用该偏置、有限接触区域与法向，
  不是将整根手指与物体的碰撞对全部豁免。局部预期接触查询深度上限为 1.5 mm。
- 位置伺服的闭合目标可以低于受阻后的真实手指位置。碰撞查询现在预测手指在物体表面停住，
  不再把伺服目标直接当成真实手指穿透。查询状态与实际物理状态分开，执行器仍由原 B 控制器驱动。
- 碰撞拒绝时，有可靠接触法向才仅重新对齐受阻轴；无法定位原因时仍保守保持。

本轮没有更改模型、质量、摩擦、PD、力矩上限或腕姿上限。
方块仍是自由刚体，实际抓取由接触与摩擦完成，不使用焊接、吸附或真值物体位姿驱动。

## 夹持与释放

夹持确认结合：人手闭合意图、真实编码器位置/速度、两指伺服受力、
视觉中的目标包络、与方块边长相符的双面开口，以及至少 0.25 秒稳定证据。
当前 B 方块的起始判据为两侧伺服受力均不低于 1.8 N、合计不低于 5.6 N。
这些是本模型的执行器反馈判据，不能当作真实指垫法向力或跨设备通用阈值。
编码器速度由相邻控制周期位置差估计，避免将接触求解器瞬时振动误认为仍在闭合。

只夹住角点、单边受阻或空夹不会直接确认为稳定双面夹持，界面会显示待对准/未稳定。
保持期间小幅捏合波动不松开；释放需要多个新鲜观测中的明确张手持续约 0.2 秒。
重复旧帧或缺手不能完成释放确认。

为处理夹爪遮挡导致的物体估计偏差，双指停滞、尺寸匹配且与相机位置相容时，
可用编码器约束夹持面的估计：沿闭合轴的位置校正限于 12 mm，
符合双面宽度时结合夹爪方向、相机对称类别及直立先验约束面朝向。
原始相机结果单独保留，校正不读取仿真物体真值或真实接触列表。

明确释放时，电机先降低夹紧压力，目标值可能暂时仍小于实际开度。
预测器允许这一卸压过程，并短时保留已确认的夹持几何用于仅开指检查，
最长约 0.6 秒或实际手指打开后清除。相机短暂遮挡时仍可卸压释放；
这不授权新的盲目手臂运动。

## 数据记录

原始人体点和捏合输入继续保存，额外记录：普通增益的未限幅参考、最终目标及差值、
自动精细比例/死区、夹持状态和原因、人手开度参考/辅助开度参考、
手指编码器/速度/伺服受力、原始相机中心/接触校正中心、最后碰撞查询的物体估计姿态、
受阻轴与释放预测状态。
辅助后的指令标记 `human_with_auto_grasp`，不会伪装成未经辅助的人体原始动作。
参考差值还可能包含工作区及速度限制，元数据已说明，不能将其全部当成纯辅助位移。
普通运行的视频/图像保存方式未变；控制日志本身不等于可直接训练视觉策略的数据集。

## 验证证据与边界

保存 RGB 同段录像的真实 OpenCV/MuJoCo 窗口检查：优化后整体控制约 19.48 Hz，
293 帧执行器动作重放 PASS，qpos/qvel 最大差异为零。
增加了远处无效预测的裁剪；裁剪不省略实际碰撞检测，进入近场仍执行完整接触规则。
这只是该录像片段的性能，不代表所有真人抓取阶段都恒定达到该频率。

最终完整回归：B 527 项检查（3 项跳过，其余通过），A 11 项通过。
覆盖增益变化不跳动、远处原有映射一致、缺手保持、真实张手释放、旧帧拒绝、
物体真值不进入辅助几何、内侧/背面/深接触分类和闭合伺服目标预测。
100 帧软件输入的完整运行通过记录校验及动作重放，qpos/qvel 最大差异为零。

十组不同位置/偏角的夹持物理专项检查：8 组离桌至少 3 cm 并保持 2 秒，10 组均可正常释放。
通过组实际稳定保持约 3.7–5 秒。两组边缘/角点条件未满足通过标准，失败结果保留。
测试使用原 B 初始腕姿限制，以位置 IK 设置测试开始时的对准位置，再执行真实动力学闭合、提起和释放。
**它是对准后的夹持专项验证，不包含从待机到方块的完整人工过程，也不是新真人操作成功率。**

证据位于 `outputs/auto_grasp_20261026/`：
`physical_final_matrix.json`、各组 `physical_grip_final_matrix_*.json`、
`full_regression_final.log`、`verification.json`、`performance_comparison.json`。
最终性能优化后，另以原腕姿进行一次真实动力学夹持复核，离桌约 3.53 cm、稳定约 3.7 秒并可释放，
见 `physical_grip_optimized_smoke.json`。早期被阻挡、滑落及未通过案例的日志也保留。
修改前源文件在该目录的 `before/`。
