# 连续夹爪：避免尚有间距时提前全闭

标定 READY 只表示两类端点数据满足拟合条件，不证明中间手势与夹爪开度成比例。上一轮端点开合录像通过后，本轮中间开度录像暴露了提前饱和问题。

## 原因与修改

原代码把用于类别判断的保守端点也用于连续插值：closed 为样本95分位，open 为5分位。本机个人数据的 r3 closed 约0.349、open约0.888，导致小间距被裁成0%、尚未充分张开就达到100%。此外，二维间距此前只用来拒绝严重冲突，未用于连续开度；三维估计偏小时，即便二维仍显示手指分离，也可能给出全闭。

现在分开两类用途：

- 原有 closed/open、开关类别判据保留。
- 新增 `continuous_closed` / `continuous_open`，分别取每类各次稳定采样中位数的中位数。连续插值使用这些典型端点，减少保守分类边界对可控范围的压缩。
- 二维、三维均有有效个人端点，且归一化开度差不超过原有0.4冲突门槛时，连续开度取二者较大值，避免单目三维距离偏小抹掉画面中可见的间距。这会偏向保留开度，真正捏合时也需要复测能否充分闭合。
- 二维不可观测时仍用三维；冲突、丢失、时序异常时保持上次开度；不凭空补手指间距。原有滤波、鲜帧确认、机器人限速、碰撞检查与动力学参数保留。

已有原始标定试次在加载时重新拟合，自动得到新增端点，无须重新采集20次。成功退出仍按原流程保存个人文件。手腕的位置映射未改。

## 证据与验证

本轮录像的原始特征与时钟回测，旧实现复现记录中的开度参考，最大误差为0。一处视频中手指仍分开的采样：r3约0.337、r2约0.499，旧指令约0.008%，新指令约21.3%。本段新参考仍可接近0%并达到100%。这些是同一输入下的参考指令差异，不是新物理执行结果。

旧参考低于1%的有效控制行中，有84行的新参考超过10%。不能把这84行全称为误闭合修复数量：其中也可能包含真正接触时的估计波动，需结合录像及新实时结果判断。新策略优先避免提前全闭，不能保证每一种主观“半开”都恰好对应50%。

新增6项回归覆盖典型端点、小间距保留、连续中间值与两端可达、二维/三维冲突保持、二维缺失回退、开关模式保持旧行为。现有端点测试使用独立软件标定数据，避免混入本机个人文件。完整 B 回归396项，393通过、3跳过；A接口11项全部通过。
